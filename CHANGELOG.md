## [Unreleased]

### Added
- Write-ahead log (WAL) for task durability — buffered writes, periodic checkpoint, crash recovery
- Rich CLI progress display for `osintote recon` command with live progress bars, colored findings, scrollable logs, summary panel
- Target management UI (`/targets` page) with add/list/remove forms, lazy-loaded routes
- Settings management UI (`/settings` page) with AI config editor, default recipe selector, output format picker, theme toggle
- API Keys management UI with add/edit/delete, status indicators, primary/fallback indicator
- Desktop notifications (`BrowserNotifier.svelte`) with platform detection (macOS/Windows/Linux)
- Error handling framework with severity tiers (info→toast, warning→toast+banner, error→banner+log, critical→banner+log+notif)
- SSE log streaming endpoint (`/api/logs/stream`) with real-time filtering and severity coloring
- LogsPanel component with auto-scroll, export, and filtering
- Task lifecycle API with status transitions and SSE progress streaming
- Recipe system with JSON config, bundled defaults (quick-scan, full-scan, passive-only), topological sorting
- HTTP probing stage with configurable timeout, status code filtering, probe paths
- Report generation service with JSON, Markdown, and HTML exporters — standalone HTML reports with vis.js network graphs
- CLI progress display with `rich.Live`, per-stage progress, findings table with status icons, error panel, summary panel
- Project scaffolding: `Makefile` (uv-based workflow), `.editorconfig`, `uv.lock`
- CI/CD: GitHub Actions workflow (pytest, mypy, ruff, npm build, Docker)
- Pre-commit hooks: ruff, mypy, trailing whitespace, EOF
- Docker multi-stage build with Node and Python stages
- Docker image publishing workflow (ghcr.io, multi-arch, semver/SHA tags)
- PyPI packaging with hatch build backend
- Callback system with safe shell command execution (`shlex` + `asyncio.create_subprocess_exec`) and HMAC-SHA256 webhook signing
- Comprehensive documentation: README, getting-started, CLI reference, web UI guide, security, FAQ, API reference, recipes, ADRs

### Changed
- Replaced default SvelteKit light theme with dark OSINT tool aesthetic
- Fixed critical CSS loading issue (`import './layout.css'` in `+layout.svelte`)
- Upgraded `/api/tasks/{id}/events` to SSE streaming (`/api/tasks/{id}/stream`) with heartbeat and buffered playback

- PBKDF2 salt storage/restore in `KeyStorage`
- `EncryptionManager.save_key` key derivation order
- Logging `record.pid` (now uses `os.getpid()`)

- Svelte 5 runes compliance (explicit closing tags, `$props()` destructuring)
- SSR `document` access errors with `browser` guard
- `AsyncGenerator` typing in error routes
- HTTP probe mock patching at correct module level
- IP URL path separator in `HttpProbeStage`
